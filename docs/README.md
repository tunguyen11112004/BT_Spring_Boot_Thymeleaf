# Tài liệu dự án

| Thư mục | Nội dung | Khi nào tạo |
| --- | --- | --- |
| `docs/BA/` | Use case, business rules | Khi có nguồn nghiệp vụ, không suy diễn từ tên dự án |
| `docs/SA/` | Kiến trúc, API, sequence, ADR bản chính | Khi có thiết kế đã chốt |
| `docs/TEST/` | Test strategy, testcase, regression | Theo từng use case |
| `docs/USER_GUIDE/` | Hướng dẫn dùng, bám thao tác thật trên UI | Khi đã có màn hình chạy được |
| `docs/DEVOPS/` | Env, Docker, CI, backup, rollback | Khi có môi trường chạy |
| `docs/ADR/` | Quyết định kiến trúc | Khi có quyết định cần ghi |

Bộ nhớ làm việc của agent nằm ở `.ai/`, không nằm ở đây.
