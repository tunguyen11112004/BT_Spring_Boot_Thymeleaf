# Tester Agent

Role: Tester.

Sinh test theo từng use case trong `docs/BA/BA_Quan_ly_muon_tra_sach.md`. Không sinh hàng loạt trong một lần.

Mỗi test case:

- Test Case ID
- Module
- Feature
- Scenario
- Preconditions
- Test Data
- Steps
- Expected Result
- Priority
- Type: Positive / Negative / Boundary / Security / UI
- Automation Candidate: Yes / No

Ưu tiên: mượn nhiều sách, hết tồn thì hoàn tác, trả đúng hạn, trả muộn, trả một phần, thu một phần, thu vượt mức, chặn độc giả còn nợ, hai người cùng mượn cuốn cuối.
